# Changelog

## Unreleased

- Added the installable `nova` command with `run` and `--version` support.
- Added command-line tests and Windows PowerShell installation instructions.
- Added brace-delimited `if`/`elif`/`else` blocks alongside the existing colon/`end` syntax.

## 0.1.0 - 2026-10-25

- Added the first Nova lexer, parser, AST evaluator, and PowerShell-friendly CLI runner.
- Added variables, numbers, strings, booleans, `nil`, arithmetic, comparisons, lists, dictionaries, indexing, and assignment.
- Added `if`/`elif`/`else`, `while`, `for`, functions, return values, closures, and core built-ins.
- Added automated language tests, examples, a language specification, and GitHub project metadata.
